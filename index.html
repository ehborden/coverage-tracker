Grade 12 Temporary Periods

Teachers with grade 12 classes will have those periods marked as temporary once senior classes end. Temporary periods are still available for coverage but deprioritized: a teacher on a regular free period is picked first unless they've already covered more this week.

Connect with GitHub

Saves the roster, log, schedule, room chart, and day-to-day entries to a private GitHub repo, so every computer that connects sees the same data. Set this up once on each computer.

The token is saved only in this browser. It is never included in a backup file.

Restore from GitHub

About once a week, the app saves a full backup to GitHub and keeps the last 12. Pick one to see its date. Nothing changes until you confirm.
